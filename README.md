# Om Shanti Web v2

Versión completa de la home de Om Shanti.

Incluye:
- Portada emocional aprobada
- WhatsApp real
- Instagram real
- Capacidad 2 a 4 huéspedes
- Tigre centro, a 200 m del río y de la ciudad
- Pet friendly
- Galería con fotos reales
- Opiniones de huéspedes
- FAQ
- Diseño responsive

## Publicación en GitHub Pages
1. Crear un repositorio.
2. Subir todo el contenido de esta carpeta.
3. Settings > Pages.
4. Deploy from a branch.
5. Branch: main / root.
6. Guardar.
7. Conectar el dominio propio desde Custom domain.
